# SweetBite Bakery Management System

SweetBite Bakery Management System is a Java application developed to help manage bakery activities such as customers, cakes, orders, bakers, and payments.

## Main Features

- Customer management
- Cake management
- Baker management
- Order management
- Payment management
- User registration and login
- Reports

## Technologies Used

- Java
- Java Swing
- Java RMI
- Hibernate
- PostgreSQL
- NetBeans

## Project Structure

The project has two main parts:

- **Client:** Contains the user interface and allows users to interact with the system.
- **Server:** Handles the application logic and database operations.
